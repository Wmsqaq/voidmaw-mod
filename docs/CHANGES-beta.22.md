# beta.22 — 奇点核心锁死

## 新增

奇点核心（Singularity Core）从此**无法离开物品栏第九格（快捷栏最右）**：

- **固定第九格**：每 tick、进服、重生后自动校正；第九格被普通物品占用时，普通物品自动挪到其它空位（背包满才掉在玩家脚下）。
- **无法在界面中移动**：点选、Shift 点击转移、拖拽分发、Q/Ctrl+Q 丢弃、数字键 9 交换、双击收集、创造中键克隆等全部被服务端拒绝。
- **按 Q 不丢出**：手持核心在游戏内按 Q / Ctrl+Q 直接无效（客户端与服务端双重拦截，无掉落物生成）。
- **无法副手交换**：手持核心按 F 无效。
- **无法进容器**：箱子等界面内点击被拦；对世界直接放置的路径同样封死——展示框/发光展示框、饰纹陶罐、书架（含潜行整栏交换）、盔甲架、悦灵等拿不走核心；F 键副手交换在服务端撤回并强制回同步。
- **创造模式封堵**：直接改槽位/丢弃的核心数据包（含 slot -1、快捷栏槽 44）一律拒绝并回同步。
- **死亡不掉落**：死亡时核心不生成掉落实体；重生后自动回到第九格（keepInventory 或普通死亡均一致）。
- **多余核心自动清理**：任何途径出现的第二份核心会被清除，仅保留第九格一份。

## 实现说明

- 新增服务端 Mixin：`ScreenHandlerMixin`（槽位点击）、`ServerPlayNetworkHandlerMixin`（点击/创造/玩家动作包，注入点在 `forceMainThread` 之后保证主线程）、`PlayerInventoryMixin`（dropAll 跳过核心掉落、dropSelectedItem 拦截 Q）、`ShelfBlockEntityMixin`、`ItemFrameEntityMixin`、`DecoratedPotBlockEntityMixin`、`LivingEntityMixin`（equipStack 拒绝核心，玩家豁免）。
- 首次进服礼包改为直接补到第九格（不再先入包再尝试丢弃），杜绝满背包时把核心丢成掉落物。
- 回归测试新增 `CoreLockRegressionTest`：点击规则行为断言 + 强制类加载校验全部 Mixin 注入点（写错会在回归阶段立刻失败）。

## 兼容性

- 旧存档中已存在的核心：进服后自动归位第九格、多余份数清除。
- beta.21 之前遗留的掉落实体核心：捡起后会被归一到第九格，不会造成复制。
- 黑洞吞噬、成长保留、无限等级、全高度吸收等 beta.21 行为不变；黑洞视觉未改动。
