# beta.21 玩法变更与验证

- 每位玩家的质量与等级独立保存到 `<世界>/data/voidmaw/progress/<UUID>.json`，不使用 NBT。等级按保存的累计质量计算。
- 坍缩、安静关闭、Shift+右键自爆、死亡、断线后不清空成长。保存周期两秒，闭合/断线/停服再保存。进度文件损坏时拒绝开启并保护原文件；写入失败保留 dirty 重试。
- 再次开启从保留质量恢复半径、等级，每次开启重新计时 60 秒，吞噬可加时至 300 秒。旧版已经关闭并丢弃的历史质量无法从旧存档恢复。
- 前五级升级阈值仍为 0/100/400/1200/3000；Lv6≥5700，后续质量阈值 `3000+1800n+900n²`，n=等级−5。删除 Lv5 满级逻辑。无玩法等级上限；内部等级使用32位整数。
- Lv6 以后半径继续以 `7+2 ln(等级−4)` 增长，吸引移动速度保留0.8格/tick执行上限。
- 最终自爆规则按用户纠正改为平缓增长：`3+0.75×(等级−1)^0.75`。以普通苦力怕威力3起步，Lv2=3.75、Lv5≈5.12、Lv10≈6.90、Lv25≈11.13。自爆仍按原版爆炸语义执行，质量与等级不消耗。
- 方块吞噬覆盖圆盘水平范围内从玩家脚底平面直到当前维度顶层，不再有局部高度/等级硬度限制。循环扫描而非随机抽样，每tick检查最多4096位置、吞噬8块，逐步清空整根柱体。未加载区块不强制加载；保护标签、不可破坏块和液体仍保留。生物门槛仍保留，生物查询高度没有跟随方块改为世界顶部。
- 取消本模组移除玩家渲染状态的处理，变身时模型保持可见。不会主动清除原版隐身药水等其它来源的效果。
- 删除旧满级HUD，持续显示下一级质量阈值。新 mass_sync_v3 使用int等级/double质量，修复超过127级或高质量float截断。新版客户端能读取旧频道，建议联机两端同版。

## 自动验证

`gradlew build` 的Fabric回归运行覆盖：重开保持质量/等级，JSON重读恢复、低值写入不回退、倒计时重新计时；Lv6/Lv1000阈值/边界；全高度扫描最后层；等级1000与小数质量网络round-trip；苦力怕基准与次线性增长；原仓库持久化/失败重试等回归。

最终runServer验证服务端初始化、指令树和正常保存停服。此次没有新增完整GUI测试；圆盘纹理沿用beta.20已由用户确认正常的资源，仅删除宿主隐藏。高等级/极密集柱体需更长吸收时间，预算只限制每tick执行量，不截断柱体高度。
