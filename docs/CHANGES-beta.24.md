# beta.24 — 修复吞噬几何 bug 与 HUD

## 修复（关键）

- **只吞 X 轴的根因**：beta.23 的截面行裁剪里，z 方向边界错误地减去了**区块 X 坐标**而不是区块 Z 坐标。玩家所在区块 cx≠cz 时，圆盘在 z 方向被钳成 1 格——整个吞噬范围塌缩成一条沿 X 的直线。现在 x 距离用区块 X、z 边界用区块 Z，分别计算。
- 回归测试此前恰好用了 cx=cz=0 的对称场景掩盖了该 bug；已补充**非对称区块坐标**断言（含逐格圆成员校验），此类错误今后会在 CI 直接失败。
- **吸收不再"迟钝"**：每 tick 的吞解除按总上限外，再按区块数分配**每区块配额**交错进行，圆盘各处同步崩解，不再出现某一区域长时间没动静。

## 调整

- **吞水不再增加质量**：海水/河水照常被吞（清场），但不再涨质量（海洋原本是无限质量水龙头）；岩浆仍计 1.2。
- **HUD 进度条同步面板宽度**：进度条不再固定 81px，而是始终铺满面板内宽，与 HUD 缩放/文字宽度一致。
- **HUD 文字缩短**：第一行 `Lv.3 400/1200`；第二行只保留 `半径 · 剩余秒数`（质量已在第一行，去掉重复）。

## 不变

- 吞噬速度（16 格/tick）、保护规则、质量成长、等级曲线、核心锁定、仓库等一切 beta.23 行为保持不变（几何 bug 修复除外）。
