# beta.23 — 方块吸收全面提速 + 液体可吞噬

## 新增

- **液体可被吞噬**：水、岩浆（含流动态）纳入吞噬范围；液体没有掉落与破坏音效，按专门计价给质量（水 0.3 / 岩浆 1.2，避免按硬度 100 算出天量质量）。含水方块（如含水楼梯）仍按普通方块处理，照常掉落入库。

## 优化

吞噬扫描从"逐格世界查询"重写为"区块截面（ChunkSection）直读"：

- **跳过空截面**：天空、空洞等整段 16×16×16 的空截面现在只花一次 `isEmpty()` 调用，不再逐格探测空气。
- **区块内直读 palette**：命中真实方块时不再走 `World.getBlockState` 的区块查找链路，直接从截面容器读取。
- **圆盘行裁剪**：每个区块列预先算好圆盘内的 z 区间，圆盘外的整行单元格直接跳过，不进入预算。
- **按脚底向上吃**：截面自下而上遍历，视觉上从贴近黑洞的一层开始向上崩解。
- **预算重新定价**：扫描预算 4096 → 16384（现在只统计非空截面内的真实单元格）；每 tick 吞吐 8 → 16 个方块（约 320/秒）。
- **旋转游标按区块推进**：预算耗尽时下一 tick 从下一个区块继续，不再整根柱体重复扫；未加载区块依然绝不强制加载。
- **每格 `BlockPos` 分配取消**：只有真正被吞噬的方块才分配坐标对象。

实测效果：同一柱体的全覆盖周期从 ~24 tick 缩短到 ~6-16 tick（视地形），空气密集区（地表/高空）提升最明显。

## 不变

- 保护规则：保护标签、硬度 <0 的方块仍然不吞；液体除外（本版起可吞）。
- 掉落入库、质量成长、等级曲线、黑洞视觉、核心锁定（beta.22）全部保持原样。
- 回归测试更新：`ColumnSweep` 断言替换为 `DiscSweep`（区块覆盖、旋转游标、行裁剪几何），新增液体计价断言。
