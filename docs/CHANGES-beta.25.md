# beta.25 — 自爆重构、死亡清零与深度排查

## 玩法调整

- **自爆更有劲**：爆炸威力改为 `等级基础威力 + √质量 × 0.08`——贮存的质量越多炸得越狠（质量加成上限 +12，总威力上限 24）。Lv1≈3、Lv3（400 质量）≈5.9、Lv5（3000 质量）≈9.5、高等级封顶 24。
- **自爆后质量清零**：全部能量随爆炸释放，成长文件归零，等级回到 Lv1 重新开始。
- **死亡质量清零**：无论黑洞是否开启，死亡时累计质量全部消散，并提示"由于你的死亡，%s 点质量消散于虚空。"
- **HUD 移除坍缩倒计时**：状态行只显示半径（`/voidmaw status` 仍可查看剩余时间）。

## 深度排查修复

- **礼包开关失效**：`Balance.GIVE_CORE_ON_FIRST_JOIN = false` 时，核心锁定器仍会给每位玩家凭空生成一个核心。现在开关关闭且玩家没有核心时不再创建；已有核心的玩家锁定行为不变。
- 自爆清零先于爆炸落盘：即使爆炸瞬间崩溃，也不会出现"炸完还能找回质量"的存档回退。
- 死亡路径统一：开启中死亡走安静闭合+清零，沉睡中死亡直接清零存档；两种情况都只提示一次。
- 清理了重构后残留的无用导入。

## 不变

- 安静关闭（右键）、超时坍缩、断线重登仍然**保留**累计质量与等级。
- 吞噬速度、液体规则（水免费、岩浆 1.2）、核心锁定、仓库均保持 beta.24 行为。
- 回归测试新增：自爆威力曲线（质量加成与封顶）、`HoleProgress.reset()` 落盘清零、`retain` 不允许回退。
