# beta.26 — 仓库类型化重构 + 等级吞吐

## 仓库重构：只记种类和数量

仓库从"格子堆叠"改为**类型条目**：每种物品（含组件，如附魔/潜影盒内容）占一格、数量无上限，9 页最多记录 **405 种**物品，彻底解决格子不够的问题。

- **显示**：格子显示物品图标；悬停提示显示精确数量（不受 99 堆叠显示上限影响）
- **取出**：**左键取 1 个**；**右键取一组**；**Ctrl+左键取一组**；**Shift+点击整组进背包**
- **销毁**：**Ctrl+右键销毁该类全部**（客户端需安装本模组，服务端权威校验）
- **存入**：手持物品点击任意仓库格；或在背包 **Shift+点击** 直接入库
- **整理**：按物品 ID 排序所有类型条目
- **旧档迁移**：旧版"格子堆叠"存档载入时自动合并为类型条目（同类多格合并计数），损坏文件保护、失败重试机制保持不变

技术说明：Ctrl 修饰键无法通过原版点击包传递，客户端 Mixin 将 Ctrl+左/右键转成专用 C2S 载荷，服务端在其当前页面上权威执行；纯原版客户端仍可用右键取一组、Shift 点击等基础操作。

## 吞噬吞吐随等级放大

方块变更必须留在服务端主线程（原版线程模型不允许并行改方块），因此提速采用安全路线——**吞吐随等级增长**：

- 每 tick 吞噬：`16 + (等级-1)×4`，上限 80（Lv5=32、Lv10=52、Lv17+=80）
- 每 tick 扫描预算：`16384 + (等级-1)×4096`，上限 65536
- 每区块配额随总吞吐等比放大，大圆盘各处仍然同步崩解

## 不变

- 黑洞视觉、核心锁定、自爆/死亡清零、液体规则（水免费、岩浆 1.2）均保持 beta.25 行为。
- 回归测试全面重写仓库断言：类型合并、取 1/取组、销毁、405 类容量溢出、大计数持久化、旧档迁移、损坏保护。
